Task 1: Repository Setup & First Branch
1.	Create a new GitHub repository.
2.	Clone the repository to your local machine using SSH (generate an SSH key if needed and add the public key to your GitHub account).
Generated the SSH and to git hub 
Clone using the below cmd 
CMD: git clone <SSH REPO URL>

3.	Create a new branch named after your username (e.g., Tutedude).
CMD:  git checkout -b <branchname>

4.	Commit the changes and merge the branch into the main branch.
CMD: git checkout main
CMD: git merge branch_1
CMD: git push -u origin main
